# What is MeshCore?

*INTRODUCTION · OFF-GRID MESH COMMUNICATION*

MeshCore — a portmanteau of **Mesh** (a network of interconnected devices) and **Core** (nucleus) — is a wireless communication system that operates entirely independently of the internet, mobile networks, or any other existing infrastructure.

It combines **LoRa radio technology** with advanced mesh networking to enable reliable communication over distances of tens of kilometres.

> [!NOTE]
> **Important:** MeshCore is a text-based communication system. It is specifically designed for sending text messages, GPS locations, telemetry data, and control commands. Voice calls or video are not supported.

## What makes MeshCore unique?

Unlike traditional communication systems, MeshCore requires no central server or access point. Every device in the network simultaneously acts as:

- **A transmitter and receiver** — for direct communication
- **A router** — forwarding messages on behalf of others
- **An autonomous computer** — making decisions without human intervention

This architecture makes the network robust: if one device fails, the network automatically finds an alternative route.

## Who is MeshCore for?

- **Families** — Stay in touch during travel or emergencies, without depending on a mobile network.
- **Radio amateurs** — Digital experiments and emergency communication via LoRa mesh on the 70 cm band.
- **Outdoor enthusiasts** — Hikers, campers, and adventurers communicating beyond mobile coverage.
- **Clubs and associations** — Morse clubs, hiking groups, or other groups wanting to set up their own mesh.

## Open Source with an optional licence

MeshCore is an open-source project under the MIT licence. The core is completely free: mesh routing, end-to-end encryption, room systems, and basic GPS. For advanced features such as remote repeater management, higher zoom levels on maps, and telemetry nodes, a **MeshCore Ultra licence** (£8, one-time) is available.
