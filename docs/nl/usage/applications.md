# Praktische Toepassingen

*FAMILIE · CLUBS · REMOTE STATIONS*

- **Familie-mesh** — Alle gezinsleden met een MeshCore apparaat in Room 'FAMILY-MESH'. Korte berichten, GPS-tracking en afspraken. Werkt zonder mobiel netwerk op vakanties, festivals of in afgelegen gebieden.
- **Morse-club** — Clubleden coördineren CW-activiteiten, velddagen en spotmeldingen via een gezamenlijke Room. Leden zien elkaar op de kaart en delen real-time QSO-informatie.
- **Amateur Radio Mesh** — Op de 70 cm-band met callsigns. Digitale QSO's, noodcommunicatie, zelfrouterende repeaters. Elke node identificeert zich conform amateurregelgeving.
- **Remote Station** — Node op dakterras met goede antenne, node binnen via BLE naar telefoon. Bedien je radio-infrastructuur via je eigen mesh — geen VPN of internet nodig.
